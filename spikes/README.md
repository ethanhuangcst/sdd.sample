# Spikes

本目录用于**技术探针**与**真实应用验证**：依据 [`pack/specs/`](../pack/specs/) 中的 `tech-spec.*.md` 与 [`pack/projects/`](../pack/projects/) 中的 req / brd / prompt 搭建可运行的 Next.js 应用，验证集成、性能契约与规格是否可实现。

- **`pack/`**：仅文档，不包含应用代码。
- **`spikes/`**：每个子目录对应一次探针或一门课程项目的参考实现（例如 `spikes/myday-cn`）。

当前为空；首个 spike 创建时再补充 Makefile、`dev` / `up` / `down` 与 README。
