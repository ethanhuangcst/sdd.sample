# How2Cook — 需求规格（中文）

- 依据本目录 `brd-cn.md`。业务范围以 BRD 为准，本文件把每条落成可验收的行为
- 界面仅中文。不使用 i18n，不预留第二语言
- 技术接入细节见 [`../../tech-spec-cn.md`](../../tech-spec-cn.md)：中式菜谱见「中式菜谱 HowToCook — 本地 stdio MCP」，西式与其他见「西式菜谱 RecipeWiki — 远程 MCP」与「西式菜谱 TheMealDB — REST API」，翻译见「对话 LLM」
- 本项目用到能力：对话 LLM（只用于翻译）、三个菜谱来源。不使用图像、地图、天气、星座、宝可梦

## 「数据来源与翻译」

- 菜系统一为三档：中式（HowToCook）、西式与其他（RecipeWiki 与 TheMealDB）。每条菜谱标注来源名
- 菜谱 MCP 和接口返回的菜谱信息，在展示前用「对话 LLM」翻译成界面语言。来源语言与界面语言一致时不翻译
- 翻译范围：菜名、食材名、用量说明、步骤、分类名。来源产品名（HowToCook、RecipeWiki、TheMealDB）不翻译
- 译文按「来源 + 菜谱 id + 语言」缓存于 `data/`，带最近更新时间；命中缓存不再调用
- 翻译提示词：

```text
你是翻译。把下面的菜谱内容翻译成中文。
只翻译原文。保留食材的用量与单位。不要添加原文没有的步骤、食材或建议。
菜名首次出现时给中文译名，并在括号里保留原文菜名。
```

- 来源没有的字段显示占位（如「来源未提供」），不编造
- 单一来源故障只影响该来源的区域，页面说明原因，其余来源照常

## 「用户账户」

- 注册：用户名（必填，2–32 字符）、邮箱（必填，格式校验）、密码（必填，至少 8 位，含字母和数字）。校验未通过留在本页并标出未通过项
- 登录：邮箱与密码。错误时用同一句通用提示，不区分邮箱不存在与密码错误
- 忘记密码：输入注册邮箱发送重设邮件；未注册邮箱与已注册邮箱返回同一句提交成功提示
- 页头：已登录显示「你好，{用户名}」与按钮「退出」；未登录显示「登录」「注册」入口
- 收藏、购物清单、「做过」记录挂在用户下，保存在本机 `data/`。密码只存哈希，不存明文

## 「找菜」（首页）

首页从上到下：页头、菜系切换、分类浏览、搜索、按食材找、页脚。

- 菜系切换：中式 / 西式与其他。切换保留已输入的搜索词
- 分类浏览：按当前菜系的分类列出菜谱卡片（图、名称、来源标签、时间或份数，来源有则显示）
  - 中式分类来自 HowToCook 的分类枚举（水产、早餐、荤菜、素菜、主食、汤、甜品、饮品、调料、半成品加工）
  - 西式与其他：RecipeWiki 的 tag 列表与 TheMealDB 的分类列表合并去重
- 搜索：按菜名关键词在当前菜系内搜索；来源各查一次，结果合并去重。无结果显示「未找到菜谱，可更换关键词」
- 按食材找：用户输入手边食材（多个），把食材词作为关键词在当前菜系检索。结果按匹配程度由高到低；无结果时说明可更换食材
- 随机来一道：中式用 HowToCook 的按人数推荐取一道；西式与其他用 TheMealDB 随机接口。结果直接进入「菜谱详情」
- 每张卡片标注来源。点击进入「菜谱详情」

## 「菜谱详情」

- 展示：图、菜名、菜系与分类、来源、份数、准备/烹饪时间（来源有则显示）
- 食材清单：名称与用量
- 份量缩放：人数输入框（默认来源份数）。改动后食材用量按比例换算，本地计算，不请求任何接口。步骤文字里嵌的数量不换算，页面对此说明一句
- 分步做法：编号步骤
- 操作：「加入购物清单」「收藏」「标记做过」即时生效，提示「已加入」并 3 秒淡出
- 数据质量：显示来源与最近更新时间；译文处显示「内容由 AI 翻译，以原文为准」

## 「购物清单」

- 清单按菜谱分组，每组列出该菜谱食材与用量
- 点一项划掉一项；移除一个菜谱即移除该组
- 不合并跨菜谱的同名食材

## 「收藏与历史」

- 「我的收藏」网格展示收藏菜谱；点击进入详情
- 「做过」记录展示最近做过的菜与日期；可再次进入详情

## 「数据质量」

- 每道菜显示来源与最近更新时间
- 译文单独标注翻译状态；来源没有的字段显示占位
- 单一来源故障只影响该来源区域，页面说明原因

## 「性能」

- 分类与搜索加载时立即展示已缓存的译文
- 满足找菜与详情的时延目标
- 避免不必要的重复请求与重复翻译。等待或失败时说明原因

## UI/UX 设计要求

- 干净、温暖、有生活感。像一本翻开的菜谱，不是后台仪表盘
- 内容页单列通栏分区卡片：找菜与详情各自成卡
- 主操作动词与结果一致：「收藏」「加入购物清单」点后立即生效并有提示
- 空、等待、失败都说明下一步。失败的区域只显示自己的说明
- 键盘：焦点可见。Escape 或点击遮罩关闭弹窗。状态不只靠颜色
- 桌面和手机：控件不被裁切
