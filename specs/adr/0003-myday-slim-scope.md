# ADR 0003 — MyDay 精简范围

日期：2026-10-15 · 状态：已采纳

## 背景

MyDay 一轮要走完验收。档案保存、浏览器定位、星座星盘、餐厅浮层，以及按大陆、香港、其他地区切换天气服务，都会加长这一轮。

## 决策

1. **档案**：不做列表、保存和再次打开。不写 `data/`。照片只放在这一次穿搭请求里。
2. **地点**：只手输城市。不做浏览器定位。
3. **天气**：继续用 Open-Meteo。不调用高德天气，也不调用 Google Weather。坐标按技术规格里这一家地图供应商的约定交给 Open-Meteo。天气失败只写在「你的状态」里。状态总结、行程和穿搭仍开始。
4. **星座**：MyDay 不调用星盘。出生日期只用于本地计算周岁和星座。不收集出生城市。技术规格里的星座 MCP 保留给其他项目。
5. **推荐**：状态总结的输入是位置、今天在做什么、心情、天气。行程和穿搭文字的输入是星座、性别、位置、今天在做什么、心情、按经度算出的当前时间、天气。天气失败时，这三份文字里的天气写「未知」。行程是一段话，写吃什么、做什么，并贴合该星座的常见性格，写出星座名。不写去哪里，不用「衣、食、住、行、玩」当小标题。不另写性格分析或运势。穿搭写成一段，仍要能分出上装、下装、鞋和一件配饰。生图用穿搭文字和这一次上传的照片，面容以照片为准。提示词写在中文需求里。姓名用于称呼。
6. **地图**：一次运行只用一家地图。`req-spec-amap.md` 只用高德，验收地点是「上海 爱琴海」。`req-spec-gmap.md` 只用 Google Maps，供中国大陆以外的中文演示，验收地点是「台北 士林」。提交只做一次该供应商的地理编码。没有结果则留在第一页。技术规格不新增双供应商章节。
7. **餐厅**：未输入菜系不查找。吃点好的只用这一家地图。不把 3 公里当作结果上限，只查一次。列表由近到远。高德一行显示名称、距离、地址、类型、电话，缺电话或类型时写「无」。Google 一行显示名称、距离、地址。点击一行，新标签打开该供应商在技术规格里的地图链接。不做浮层，不按行请求详情。
8. **时区**：位置可用后，用本次采用的坐标经度在本地计算时差。小时数等于经度除以 15 后四舍五入到整数，0.5 向远离 0 的方向取整，限制在 -12 到 14。当前时间等于 UTC 加上这个时差。不请求外部时区接口。这个时差来自经度，不是行政区的法定时区。
9. **重新规划**：第二页按钮「重新规划」回到第一页，并清空本次填写和本页结果。

## 后果

- `pack/projects/myday.cn/req-spec-amap.md` 和 `pack/projects/myday.cn/req-spec-gmap.md` 按本决策写。演示前只把其中一份复制为 `specs/req-spec.md`。`pack/projects/myday.en/req-spec.md`、`pack/projects/myday.en/req-spec-en-in-shanghai.md` 和当前的 `specs/req-spec.md` 仍是旧范围。
- 验收改为：手输该份需求里的地点后，看到天气、状态总结、行程、穿搭文字和穿搭图。输入菜系后看到按距离由近到远的餐厅，一行打开这一家地图。「重新规划」清空并回到第一页。
