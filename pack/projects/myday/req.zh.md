# MyDay Web App
- 一款每日计划 Web 应用。对话与图像共用一把 Quanzil Key：对话模型 `gpt-6-astra`，图像模型 `gemini-3.1-flash-lite-image`。天气用 Open-Meteo，星座用 Pandorium MCP。地图按地区选用，见下一条。能力细节见 [`../../specs/tech-spec.zh.md`](../../specs/tech-spec.zh.md) 第 1 节与第 5 节
- 帮助用户以个性化推荐开启每一天
- 面向中国大陆、香港和澳门。中国大陆的地点与餐厅以高德地图为来源；香港和澳门以 Google Maps 为来源
- **界面语言：仅中文。** 不要求 i18n / 多语言框架；用户可见文案可直接使用中文（无需 message key / locale 目录）

## 概述
- 入口页面：用户填写个人信息并保存为个人档案
- 提供星座洞察
- 根据用户档案、天气、今日心情及星座洞察，推荐今日穿搭
- 基于用户位置（自动获取；不可用或过粗时支持手动输入）列出附近餐厅

## 需求规格

### 档案列表
- 以网格视图展示所有现有档案
- 每个档案以卡片形式展示，包含姓名与照片
- 点击档案卡片「规划我的一天」
- 点击「新建档案」按钮进入「新建档案」页面

### 新建档案
- 用户填写个人信息
  - 姓名（必填）
  - 性别
  - 出生日期（必填）
  - 上传个人照片（必填）
  - 身高
  - 体重
  - 职业
- 点击「保存」按钮保存档案


### 规划我的一天
- 「我的档案」区域：查看/编辑档案信息，包含「删除」功能（需二次确认）
- 「我现在的状态」区域：
  - 获取当前位置（默认浏览器定位，坐标为 WGS-84）。定位失败、精度过粗（坐标约 `35.86, 104.20`，或 `accuracy > 8000m`）时视为不可用，须手动输入城市/商圈，禁止带着无效坐标进入今日计划
  - 用户手动输入「我现在的心情」，如「兴奋」
  - 用户手动输入「我今天在做什么」，如「旅行」
- 点击「规划我的一天」按钮后的行为：
  - 后台调用星座MCP获得「当日运势」。
    - 结合用户输入的「我现在的心情」，「我今天在做什么」信息及从 Pandorium MCP 获取的星座数据，使用 Quanzil LLM 给出具体建议，如「今日宜做 / 今日不宜」，以及 AI 能想到的其他趣味建议
    - 「当日运势」获取成功后，不在本页显示，在「我的今日计划」显示
  - 后台调用天气MCP获得「当日天气」。
    - 根据当前位置，调用天气MCP，获得「当日天气」
    -「当日天气」获取成功后，不在本页显示，在「我的今日计划」显示
  - 生成「当日运势」和「当日天气」的两步应该是同步发生，不应该是穿行的，以节约时间
  - 等待过程中UI需要有“正在为您的一天生成洞察”友好提示
  - 「当日运势」和「当日天气」获取成功后，进入「我的今日计划」

### 我的今日计划
- 顶部区域
  - 「你好，{姓名}」 + 照片
  - 展示个人信息，包括年龄与星座
- 天气区域
  - 展示「规划我的一天」按钮提交时后台获得的「当日天气」数据
  - 若上游返回的天气描述为英文（或 WMO 天气代码等非中文展示形态），须翻译/映射为中文后再展示给用户
- 星座洞察区域
  - 展示「规划我的一天」按钮提交时后台获得的「当日运势」
  - 在页面展示详细的个人星座洞察

- 穿搭推荐区域
  - 根据天气、「我现在的心情」、「我今天在做什么」、「当日运势」和「当日天气」，使用 Quanzil LLM 生成穿搭推荐（以文字形式展示）
  - 使用 Quanzil 图像模型 `gemini-3.1-flash-lite-image` 生成今日穿搭的人像图
    - 若用户档案中包含了照片，必须用该文件作参考图生成高度写实虚拟形象——读不到照片时要报错/可重试，禁止静默改走纯文生图
    - 若未上传，则根据用户档案信息生成
    - 生成的图像应与 LLM 生成的穿搭推荐相符

- 展示**今日吃什么**推荐：
  - 让用户选择菜系（日式、西班牙式、意式、快餐、粤菜等）
  - 按地区调用地图：中国大陆用高德，香港和澳门用 Google Maps。查找当前位置 3 公里内的合适餐厅（半径不扩大）。大陆把 WGS-84 转为 GCJ-02 后再查高德；香港和澳门用 WGS-84 查 Google Maps
  - 以列表形式展示结果，按距离排序；无结果须说明原因（换菜系或改地点），禁止空白列表
  - 每条展示餐厅名称、距离、地址。不展示评分、评论数或点评摘要
  - 香港和澳门若有地点照片，经服务端代理展示；客户端图片地址不带地图 Key。没有照片时不显示破图
  - 点击餐厅后弹出浮层，展示餐厅详细信息。大陆内嵌高德地图，香港和澳门内嵌 Google 地图，显示位置及导航。支持关闭、Escape、点击背景关闭

### 性能与用户体验
- 内容生成过程中始终向用户展示提示和进度
- 展示内容时无需等待所有内容就绪——各部分内容准备好后即刻逐块展示
- 各区域独立加载：约 10 秒后展示「还需要更多时间」并继续等待；目标每个区域 ≤20 秒就绪（与 `../../specs/tech-spec.zh.md` 性能契约一致）。仅在上游失败或等待路径结束后仍为空时使用本地降级——不要在约 10 秒时静默切降级
