# MyDay Web App
- 一款每日计划 Web 应用，帮助用户以个性化推荐开启每一天
- 只服务中国大陆，只用高德。不配置 Google Maps。接口见 `specs/tech-spec.md`
- 地点是否在中国大陆，用高德地理编码结果判断，不写经纬度范围。浏览器定位先做一次逆地理编码。手输地点用正向地理编码的结果。不在中国大陆时提示「高德地图不支持这个地点」，留在 page 3，不开始运势和天气。出生城市也用高德解析；不在中国大陆时同样提示，两路都不开始
- 界面仅中文

## 概述
- 入口页面：page 1 「档案列表」：展示已有档案卡片列表
- page 2 「新建档案」：用户填写个人信息并保存为个人档案
- page 3 「规划我的一天」：用户提供今日心情和做什么，获取用户位置（自动获取；不可用或过粗时手输城市）。位置可用后，点击「规划我的一天」才同时获得「当日运势」和「当日天气」
- page 4 「我的今日计划」：展示 page 3 获得的「当日运势」和「当日天气」。生成今日穿搭文字和真人穿搭图。按 page 3 的位置，用户选择菜系后列出附近餐厅

## 需求规格

### page 1 档案列表
- 以网格视图展示所有现有档案
- 每个档案以卡片形式展示，包含姓名与照片
- 点击档案卡片，加载该档案的信息后进入 page 3「规划我的一天」
- 点击「新建档案」按钮进入 page 2「新建档案」页面

### page 2 新建档案
- 用户填写个人信息
  - 姓名（必填）
  - 性别
  - 出生城市（必填）
  - 出生日期（必填）
  - 上传个人照片（必填）
  - 身高
  - 体重
  - 职业
- 点击「保存」按钮保存档案。姓名、出生城市、出生日期或照片未填时，不保存，留在 page 2，并标出未填项。出生城市填写一个城市，例如「上海」。保存成功后回到 page 1「档案列表」，新档案出现在列表中


### page 3 规划我的一天

用户在本页确认档案、输入当前状态。本页只取得「当日运势」和「当日天气」，不在本页展示。展示在 page 4「我的今日计划」。两项都取得之后才进入 page 4。

- 「我的档案」区域：查看/编辑档案信息，包含「删除」。编辑保存后留在本页。两路已经开始后，这次编辑不重跑这两路。删除需二次确认。确认后该档案从列表消失，并回到 page 1「档案列表」。若「当日运势」或「当日天气」还在进行，两路都停止。完成后也不进入 page 4
- 「我现在的状态」区域：
  - 获取当前位置（默认使用浏览器定位）。定位失败、精度大于 8000 米，或坐标约在 `35.86, 104.20`（约 0.05 度以内）时，视为无效，须手动输入城市/商圈
  - 手输城市先变成可用位置。这段不计入后面两路的等待。无法变成可用位置时，留在本页并说明需要重填。点击不开始两路
  - 位置仍无效时，不开始「当日运势」和「当日天气」，也不进入 page 4
  - 用户手动输入「我现在的心情」，如「兴奋」
  - 用户手动输入「我今天在做什么」，如「旅行」
- 位置可用之后，用户点击「规划我的一天」，才同时开始「当日运势」和「当日天气」。位置还无效时，点击不开始这两路，也不进入 page 4。两路都开始后一起等待。不要等一路结束再开始另一路。
  - 运势：结合星座、「我现在的心情」和「我今天在做什么」，生成「当日运势」，包含「今日宜做 / 今日不宜」以及其他趣味建议。星盘的位置用档案里的出生城市，不用当前定位。点击后先把出生城市解析成经纬度，时区用 `Asia/Shanghai`。解析失败则留在本页，说明需要修改出生城市，两路都不开始。这段不计入两路的等待。同一档案、同一日，只调用一次 `calculate_natal_chart`。运势文字用对话模型写，不调用 `get_current_transits`。再次点击时，用已经取得的星座数据，结合当时的心情和「我今天在做什么」重新生成运势文字。两路已经开始后，再改出生城市，这次不重算星盘
  - 天气：按当前位置取得「当日天气」。再次点击时按当前可用位置重新获取。当前位置只用于天气和餐厅
- 约 10 秒内，本页只显示一句「正在为您的一天生成洞察」。超过约 10 秒后，这一句改为「还需要更多时间」，并继续等待
- 两路里有一路失败时，留在本页。标出失败的那一路，并提供重试。用户点击后只重试这一路，不自动重试。保留已经成功的一路。不要进入 page 4
- 「当日运势」和「当日天气」都成功后，进入 page 4「我的今日计划」

### page 4 我的今日计划

天气区域和星座区域直接展示 page 3 已经取到的数据，不再发起那两路请求，也不显示「正在为您的一天生成洞察」。穿搭文字、穿搭图、餐厅各自显示自己的进度。其中一块失败时，只影响这一块。失败的那一块提供重试。用户点击后只重试这一块，不自动重试。

- 顶部区域
  - 「你好，{姓名}」 + 照片
  - 展示个人信息，包括年龄，以及由出生日期算出的星座名
- 天气区域
  - 展示 page 3 取得的「当日天气」
  - 天气描述先变成中文再展示给用户
- 星座洞察区域
  - 只展示 page 3 取得的「当日运势」。其中已包含「今日宜做 / 今日不宜」和其他趣味建议

- 穿搭推荐区域使用 page 3 已经取到的「当日天气」「当日运势」，以及「我现在的心情」「我今天在做什么」。下面两块同时开始，一块不需要等另一块结束。
  - 「穿搭推荐文本」：生成穿搭推荐，以文字展示
  - 「真人穿搭生图」：生成今日穿搭的人像图。用档案中的照片作为本人形象，生成高度写实虚拟形象。读不到照片时要报错。用户点击后重试。不自动重试。禁止改成不使用照片的图

- 展示**今日吃什么**推荐：
  - 让用户选择菜系（日式、西班牙式、意式、快餐、粤菜等）。未选择菜系时不查找
  - 用 page 3 已经得到的位置，查找 3 公里内的合适餐厅。半径不扩大。page 4 不再获取定位
  - 三步都用 `/v5/place/around`，`location` 为 GCJ-02，`radius=3000`。有结果就停：第一步 `keywords` 加 `types=050000`，第二步只 `keywords`，第三步只 `types=050000`。菜系词：日式用「日本料理」，西班牙式用「西班牙菜」，意式用「意大利菜」，快餐用「快餐」，粤菜用「粤菜」
  - 以列表形式展示结果，按距离排序。无结果须说明原因：可换菜系，或返回 page 3 重选位置。page 4 不在本页改位置。返回 page 3 后，位置改好并再次点击「规划我的一天」，才按上面的规则重新取得天气和运势。之前的 page 4 结果不再使用。禁止空白列表
  - 每条展示餐厅名称、距离、地址。不展示评分、评论数或点评摘要
  - 点击餐厅后弹出浮层，展示餐厅详细信息，并打开该地区的地图，显示位置及导航。支持关闭、Escape、点击背景关闭

### 非功能需求
- 本项目用到的能力：对话、图像、天气、星座、高德。不配置 Google Maps。不用宝可梦，也不用路线查询。
- 本项目这次安装：Next.js、React、TypeScript、Tailwind，以及测试用到的 Vitest。数据放在 `data/`。不安装 React Query、Zustand、RHF、Playwright。
- page 3 约 10 秒内只显示一句「正在为您的一天生成洞察」。超过约 10 秒后，这一句改为「还需要更多时间」，并继续等待。一路失败时留在本页。用户点击后只重试失败的那一路，不自动重试
- page 4 的天气和星座直接展示，不显示上面两句。穿搭文字、穿搭图、餐厅各自显示进度。一块准备好就显示这一块。一块失败只影响这一块。这三块各自计时，超过约 10 秒后各自显示「还需要更多时间」，并继续等待
- 目标每个仍在加载的区域在 20 秒内就绪。不要在约 10 秒时改成另一套内容
