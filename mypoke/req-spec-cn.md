# MyPoke — 业务需求
- MyPoke 是一款宝可梦卡（Pokémon TCG）收藏与查卡助手。它帮助收藏者查卡、管理已有收藏，并浏览官方图鉴的系列与卡牌详情。
- 主要面向需要整理收藏、快速查卡的宝可梦 TCG 收藏者。帮孩子管理收藏的家长，以及常去本地卡店的玩家也可使用。
- 宝可梦卡的数据来自官方图鉴，免费公开、无需密钥。接入细节见共用技术规格的「宝可梦 TCG 目录」章节：[`../../tech-spec-cn.md`](../../tech-spec-cn.md)

## 功能

### 用户账户

- 注册新用户（姓名、邮箱、可选头像、收藏经验等级、密码）
- 使用邮箱与密码登录
- 通过邮箱重置密码
- 已登录页面右上角页头：“Hello, [Username]” + 头像 + Logout

### 首页

- 首页由四部分组成：Header、系列总览、搜索、Footer

#### Header

- 展示品牌名“MyPoke”与导航
- 导航提供“我的收藏”入口
- 未登录时提供登录与注册入口；已登录时按“用户账户”的规定显示问候、头像与 Logout

#### 系列总览

- 展示官方图鉴的全部系列：系列名称、系列标识、卡牌总数、发布日期（图鉴有则显示）
- 点击一个系列，在该区域下方展示所选系列：
  - 系列名称、系列标识、发布日期、卡牌总数
  - 该系列的全部卡牌：图鉴缩略图、卡名、编号、稀有度
  - 每张卡标注“已收藏”或“未收藏”，判断依据是“我的收藏”的数据
  - 可按“已收藏 / 未收藏”筛选
- 点击一张卡进入“卡片详情”
- 数据来源与最近更新时间在页面上可见

#### 搜索

- 搜索框与提交按钮，支持按语言、卡名、系列代码或卡号搜索官方图鉴
- 搜索结果列出匹配的卡牌：图鉴缩略图、卡名、系列、编号、稀有度
- 同一卡名的不同印刷版本（语言、系列、变体）分别列出，用户从中选择正确版本
- 点击一条结果进入“卡片详情”
- 无匹配时显示“未找到卡牌”，并说明可以更换关键词

#### Footer

- 展示一行固定说明文字，文案由实现时决定

### 卡片详情

- 入口：在首页“系列总览”的卡牌列表、“搜索结果”或“我的收藏”的收藏列表中点击一张卡
- 弹窗或页面展示完整图鉴信息、图鉴图片与数据最近更新时间；可通过关闭、Escape 或点击外部关闭
- 若该卡已在“我的收藏”中：显示醒目的“已收藏”标签，并提供“从我的收藏移除”按钮；移除需要确认
- 若该卡尚未收藏：提供“加入我的收藏”按钮；点击直接加入，不需确认；加入成功后显示提示“已加入我的收藏”，不是弹窗，显示 3 秒后自动淡出消失

### 我的收藏

- 入口：页头导航
- 页面由两部分组成：收藏列表、卡片详情

#### 收藏列表

- 以响应式网格展示已收藏卡牌：图鉴缩略图、卡名、系列、编号、稀有度
- 可按系列、稀有度、语言筛选
- 点击一张卡打开本页的“卡片详情”；点击系列名回到首页“系列总览”并选中该系列

#### 卡片详情

- 入口：在收藏列表中点击一张卡
- 展示内容与操作遵循“卡片详情”章的规定，不在此重复

### 数据质量

- 始终显示图鉴信息的最近更新时间
- 标记过期、不完整、不可用或冲突的数据
- 单一提供方故障不得拖垮整个应用

### 性能

- 图鉴数据加载时立即展示已存储的收藏信息
- 满足首页、搜索、卡片详情与我的收藏的时延目标
- 缓存须带最近更新时间
- 使用超时、重试与回退；避免不必要的重复 API 调用

## 成功定义

收藏者能在一处管理收藏，快速查卡、查看卡牌详情与系列进度（已有 vs 缺失），数据来源与最近更新时间透明；仍以官方图鉴与实物卡牌为最终依据。
