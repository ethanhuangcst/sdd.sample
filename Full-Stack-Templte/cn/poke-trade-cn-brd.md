# PokeTrade — 业务需求

## 是什么

PokeTrade 是一款 AI 辅助的宝可梦卡（Pokémon TCG）收藏与交换助手。它帮助收藏者查卡、管理已有与想要清单、对比市场价格，并判断一笔交换或购买是否合理。它结合大语言模型（LLM）、智能体（agent）、MCP 服务与图鉴/价格数据（如 TCGdex）。它不执行交易、不处理支付，也不替代宝可梦公司（Pokémon Company）官方规则、店铺政策或交易平台条款。

## 给谁用

主要面向需要在买、卖、换之前弄清卡牌身份与价格背景的宝可梦 TCG 收藏者与轻度交换者。帮孩子管理收藏的家长，以及常去本地卡店的玩家也可使用。

## 如何拼在一起

- **Web 应用** — 账户、收藏、想要清单、卡牌卡片、交换草稿本与分析视图。浏览器只与应用后端通信。
- **poke-catalog-mcp** — 搜索卡牌，并从已批准的图鉴提供方（主选：TCGdex）获取系列、稀有度、图片与市场价格快照。
- **poke-trade-agent** — 使用 MCP 数据与 RAG 知识分析价值与交换公允性；区分图鉴事实、评估与价格预测。
- **poke-rules-rag** — 为智能体提供系列发售、赛制合法性说明、评级基础与常见交换坑点。

## 功能

### 用户账户

- 注册新用户（姓名、邮箱、可选头像、收藏经验等级、密码）
- 使用邮箱与密码登录
- 通过邮箱重置密码
- 已登录页面右上角页头：“Hello, [Username]” + 头像 + Logout

### 收藏卡片

- 以响应式网格展示已拥有卡牌，可按系列、稀有度、语言筛选
- 每张卡显示名称、系列、编号、品相（用户填写）、数量、最新价格快照、缩略图（用户照片或图鉴图），数据缺失时有明确占位
- 点击卡牌打开卡牌详情；点击系列打开系列总览

### 想要清单

- 添加用户想找的卡；显示想要数量与可选最高可接受价格
- 当想要清单中的卡出现在其他用户的公开交换报价中时高亮（若后续启用分享）
- 同一卡牌身份禁止重复想要条目，除非品相变体不同

### 添加 / 搜索卡牌

- 按卡名、系列代码或卡号搜索（经 poke-catalog-mcp）
- 出现多个匹配时选择正确印刷版本（语言、系列、变体）
- 加入收藏或想要清单；记录品相与数量
- 添加或编辑已拥有卡时，可手动上传卡牌照片（相机或文件）；照片与该收藏条目一并存储
- 有用户照片时优先作缩略图；否则用图鉴图；两者皆无则显示占位
- 校验文件类型与大小；允许在确认后替换或删除已上传照片

### 卡牌详情

- 弹窗或页面展示完整图鉴信息、图片（用户照片和/或图鉴图）与价格历史摘要；可通过关闭、Escape 或点击外部关闭
- 可在详情中上传、替换或删除卡牌照片
- 链接到交换分析；显示价格来源与最近更新时间
- 从收藏 / 想要清单移除时需确认

### 价格状态分级

- 价格信号：绿（稳定 / 接近近期均价）、黄（波动大或不完整）、红（异常 / 不可靠 / 来源冲突）— 须有文字标签与说明
- 交换公允性：绿（均衡）、黄（有偏）、红（明显一边倒）— 须有文字标签与说明
- 仅靠颜色不够

### 图鉴 / 价格 MCP — poke-catalog-mcp

- 内置 MCP：搜索卡牌并获取图鉴元数据与市场价格（在可用时含 TCGPlayer 美元、Cardmarket 欧元）
- 规范化提供方数据；标记过期、缺失或冲突的价格
- 返回标准化卡牌身份、价格快照、来源、最近更新与置信度

### 收藏提醒

- 在收藏卡片与卡牌详情上显示价格变动与数据质量警告
- 覆盖大幅波动、缺价、系列再版，以及品相相关注意事项
- 当已追踪卡牌的价格信号变得更严重时明确高亮

### 交换草稿本

- 选择给出的卡与想要的卡；显示双方合计与差额
- 支持多卡组合包；每行显示货币与来源
- 保存草稿；清空需确认

### 交换分析智能体 — poke-trade-agent

- 使用 poke-catalog-mcp 与 poke-rules-rag 分析拟议交换
- 考虑印刷稀有度、品相假设、语言、近期均价（可用时 avg1/7/30）与数据缺口
- 区分图鉴事实、评估与预测；不得将市场估值表述为保证成交价

### 交换分析

- 针对所选交换草稿的页面：双方价值、差额、波动说明、对收藏者的影响、来源、最近更新与置信度
- 可就所选交换对话（交换草稿保持在会话上下文中）
- 智能体提示词存放在独立、纳入版本控制的文件中

### 系列总览

- 针对所选系列的页面：身份、卡数、已有 vs 缺失、价格覆盖、来源、最近更新与置信度
- 可就所选系列对话（系列保持在会话上下文中）
- 智能体提示词存放在独立、纳入版本控制的文件中

### 规则 / 市场 RAG — poke-rules-rag

- 知识库：常见 TCG 交换实践、评级基础、再版意识与交易平台注意事项
- 应用启动时加载通用知识；访问新系列时按需加载系列说明
- 优先权威或来源可靠的资料；条目在可用时应含来源与日期

### 数据质量

- 始终显示价格与图鉴信息的最近更新时间
- 标记过期、不完整、不可用或冲突的数据；区分标价、最近成交与均价
- AI 价值判断不得表述为宝可梦公司、店铺或交易平台的官方估值
- 单一提供方故障不得拖垮整个应用

### 性能

- 价格更新加载时立即展示已存储的收藏信息
- 满足仪表盘、搜索、详情、系列总览与 AI 响应的时延目标
- 缓存须带最近更新时间；不得将缓存价格标为实时行情
- 使用超时、重试与回退；避免不必要的重复 API/MCP/RAG/LLM 调用

## 成功定义

收藏者能在一处管理收藏与想要清单，快速看出哪些卡或交换需要关注，理解主要价格理由及其来源与置信度，用自然语言追问，并为更公允的交换做好准备——同时仍以店铺、交易平台与当面验卡为最终依据。
