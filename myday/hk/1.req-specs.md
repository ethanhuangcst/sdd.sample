# MyDay Web 應用
- 一款融合通義千問 Qwen LLM（對話與圖像生成，經 DashScope）、高德地圖（AMap）、Open-Meteo 天氣及星座洞察（Pandorium MCP）等能力的每日計劃 Web 應用
- 幫助用戶以個性化推薦開啟每一天
- 面向中國大陸與香港；地點與餐廳數據以高德地圖為唯一來源（不使用 Tripadvisor）
- **介面語言：僅中文。** 不要求 i18n / 多語言框架；用戶可見文案可直接使用中文（無需 message key / locale 目錄）

## 概述
- 入口頁面：用戶填寫個人資訊並儲存為個人檔案
- 提供星座洞察
- 根據用戶檔案、天氣、今日心情及星座洞察，推薦今日穿搭
- 基於用戶位置（自動獲取；不可用時支援手動輸入）列出附近餐廳
- 若餐廳有高德地圖評價，則高亮顯示

## 需求規格

### 檔案列表
- 以網格檢視展示所有現有檔案
- 每個檔案以卡片形式展示，包含姓名與照片
- 點擊檔案卡片進入「規劃我的一天」
- 點擊「新建檔案」按鈕進入「新建檔案」頁面

### 新建檔案
- 用戶填寫個人資訊
  - 姓名
  - 性別
  - 出生日期
  - 上傳個人照片（可選）
  - 身高
  - 體重
  - 職業
- 點擊「儲存」按鈕儲存檔案

### 規劃我的一天
- 「我的檔案」區域：檢視/編輯檔案資訊，包含「刪除」功能（需二次確認）
- 「我現在的狀態」區域：
  - 獲取當前位置（預設使用瀏覽器定位；不可用時支援手動輸入）
  - 用戶手動輸入「我現在的心情」，如「興奮」
  - 用戶手動輸入「我今天在做什麼」，如「旅行」
- 點擊「規劃我的一天」按鈕進入「我的今日計劃」

### 我的今日計劃
- 頂部區域
  - 「你好，{姓名}」 + 照片（如有）
  - 展示個人資訊，自動計算年齡與星座
- 天氣區域：經 Open-Meteo 按當前位置坐標查詢天氣（氣溫、濕度、天氣現象、風力等）
  - 若上游回傳的天氣描述為英文（或 WMO 天氣代碼等非中文展示形態），須翻譯/映射為中文後再展示給用戶
- 星座洞察區域
  - 提供詳細的個人星座洞察
  - 結合用戶在上一頁輸入的「我現在的狀態」資訊及從 Pandorium MCP 獲取的星座數據，使用通義千問 LLM 給出具體建議，如「今日宜做 / 今日不宜」，以及 AI 能想到的其他趣味建議
- 穿搭推薦區域
  - 根據天氣、「我現在的心情」、「我今天在做什麼」及星座洞察，使用通義千問 LLM 生成穿搭推薦（以文字形式展示）
  - 使用通義千問圖像能力生成今日穿搭的人像圖
    - 若用戶上傳了照片，必須用該文件作參考圖生成高度寫實虛擬形象——讀不到照片時要報錯/可重試，禁止靜默改走純文生圖
    - 若未上傳，則根據用戶檔案資訊生成
    - 生成的圖像應與 LLM 生成的穿搭推薦相符

- 展示**今日吃什麼**推薦：
  - 讓用戶選擇菜系（日式、西班牙式、意式、快餐、粵菜等）
  - 調用高德地圖（AMap）API，查找當前位置 3 公里內的合適餐廳
  - 以列表形式展示結果，按距離排序
  - 若餐廳在高德地圖上有評價/收錄資訊，則在其旁顯示高德相關標識及簡短評價摘要
  - 點擊餐廳後彈出浮層，展示餐廳詳細資訊，內嵌高德地圖顯示餐廳位置及導航，支援關閉/Escape/點擊背景關閉

### 效能與用戶體驗
- 內容生成過程中始終向用戶展示提示和進度
- 展示內容時無需等待所有內容就緒——各部分內容準備好後即刻逐塊展示
- 每個區域的內容應在 10 秒內生成完畢（與 `2.tech-spec.md` UX 效能目標一致；超時使用本地降級）
