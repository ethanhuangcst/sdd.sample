# 準備工作

自動執行；僅在受阻時停止。

1. `npm install` from npm mirror: `https://registry.npmmirror.com`
2. 冒煙測試 DashScope（對話 + 圖像）、Google Maps、Open-Meteo、Tripadvisor、Pandorium
3. 從 `2.tech-stack.md` 中的密鑰編寫 `.env.local`（已 gitignore；勿提交）：

```env
DASHSCOPE_API_KEY=
DASHSCOPE_BASE_URL=https://llm-xcw25ck2bdvchrw4.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
DASHSCOPE_API_BASE=https://llm-xcw25ck2bdvchrw4.cn-beijing.maas.aliyuncs.com/api/v1
DASHSCOPE_CHAT_MODEL=qwen-plus
DASHSCOPE_IMAGE_MODEL=qwen-image-2.0
GOOGLE_MAPS_API_KEY=
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=
TRIPADVISOR_API_KEY=
TRIPADVISOR_BASE_URL=https://terra.tripadvisor.com/api
PANDORIUM_MCP_URL=https://pandorium.app/mcp
```

4. 實現功能（`specs/myday/req-myday.md` 中的 US1–US8）
5. `npm run dev` → http://localhost:3000
