# MyDay Web App
- 一款融合通义千问 Qwen LLM（对话与图像生成，经 DashScope）、高德地图（AMap）、Open-Meteo 天气及星座洞察（Pandorium MCP）等能力的每日计划 Web 应用
- 帮助用户以个性化推荐开启每一天
- 面向中国大陆与香港；地点与餐厅数据以高德地图为唯一来源（不使用 Tripadvisor）
- **界面语言：仅中文。** 不要求 i18n / 多语言框架；用户可见文案可直接使用中文（无需 message key / locale 目录）

## 概述
- 入口页面：用户填写个人信息并保存为个人档案
- 提供星座洞察
- 根据用户档案、天气、今日心情及星座洞察，推荐今日穿搭
- 基于用户位置（自动获取；不可用或过粗时支持手动输入）列出附近餐厅
- 若餐厅有高德地图评价，则高亮显示

## 需求规格

### 档案列表
- 以网格视图展示所有现有档案
- 每个档案以卡片形式展示，包含姓名与照片
- 点击档案卡片进入「规划我的一天」
- 点击「新建档案」按钮进入「新建档案」页面

### 新建档案
- 用户填写个人信息
  - 姓名
  - 性别
  - 出生日期
  - 上传个人照片（可选）
  - 身高
  - 体重
  - 职业
- 点击「保存」按钮保存档案

### 规划我的一天
- 「我的档案」区域：查看/编辑档案信息，包含「删除」功能（需二次确认）
- 「我现在的状态」区域：
  - 获取当前位置（默认浏览器定位）。定位失败、精度过粗（如落到中国国家质心 `35.86, 104.20`）时视为不可用，须手动输入城市/商圈，禁止带着无效坐标进入今日计划
  - 用户手动输入「我现在的心情」，如「兴奋」
  - 用户手动输入「我今天在做什么」，如「旅行」
- 点击「规划我的一天」按钮进入「我的今日计划」

### 我的今日计划
- 顶部区域
  - 「你好，{姓名}」 + 照片（如有）
  - 展示个人信息，自动计算年龄与星座
- 天气区域：经 Open-Meteo 按当前位置坐标查询天气（气温、湿度、天气现象、风力等）
  - 若上游返回的天气描述为英文（或 WMO 天气代码等非中文展示形态），须翻译/映射为中文后再展示给用户
- 星座洞察区域
  - 提供详细的个人星座洞察
  - 结合用户在上一页输入的「我现在的状态」信息及从 Pandorium MCP 获取的星座数据，使用通义千问 LLM 给出具体建议，如「今日宜做 / 今日不宜」，以及 AI 能想到的其他趣味建议
- 穿搭推荐区域
  - 根据天气、「我现在的心情」、「我今天在做什么」及星座洞察，使用通义千问 LLM 生成穿搭推荐（以文字形式展示）
  - 使用通义千问图像能力生成今日穿搭的人像图
    - 若用户上传了照片，必须用该文件作参考图生成高度写实虚拟形象——读不到照片时要报错/可重试，禁止静默改走纯文生图
    - 若未上传，则根据用户档案信息生成
    - 生成的图像应与 LLM 生成的穿搭推荐相符

- 展示**今日吃什么**推荐：
  - 让用户选择菜系（日式、西班牙式、意式、快餐、粤菜等）
  - 调用高德地图（AMap）API，查找当前位置 3 公里内的合适餐厅（半径不扩大）
  - 以列表形式展示结果，按距离排序；无结果须说明原因（换菜系或改地点），禁止空白列表
  - 若餐厅在高德地图上有评价/收录信息，则在其旁显示高德相关标识及简短评价摘要
  - 点击餐厅后弹出浮层，展示餐厅详细信息，内嵌高德地图显示餐厅位置及导航，支持关闭/Escape/点击背景关闭

### 性能与用户体验
- 内容生成过程中始终向用户展示提示和进度
- 展示内容时无需等待所有内容就绪——各部分内容准备好后即刻逐块展示
- 每个区域的内容应在 10 秒内生成完毕（与 `2.tech-spec.md` UX 性能目标一致；超时使用本地降级）
